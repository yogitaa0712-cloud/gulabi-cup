# Gulabi Cup — Jaipur Café Website

A responsive four-page portfolio website concept for a fictional café in C-Scheme, Jaipur.

## Pages
- `index.html` — home, highlights, why choose us, testimonials and CTA
- `menu.html` — responsive CSS Grid menu cards and sample pricing
- `gallery.html` — responsive image gallery
- `contact.html` — accessible contact form, hours, address and map

## Run locally
Open `index.html` in a browser, or use the VS Code **Live Server** extension.

## Built with
- Semantic HTML5 (`header`, `nav`, `main`, `section`, `article`, `footer`)
- Tailwind CSS via CDN
- CSS dark mode follows the visitor's operating-system preference, with a CSS-only header toggle on every page
- Native HTML form constraints; the demo form does not submit or store enquiries

## Before pitching to a real business
This is a realistic demo, not a verified real business. Replace the sample business name, address, phone, email, opening hours, menu/prices, testimonials and photos with approved client information. The contact form is a non-submitting preview; connect a form service or backend if enquiries should be received. Replace the illustrative map location with the exact shop address. Tailwind CDN, Unsplash photos and Google Maps require internet access.
